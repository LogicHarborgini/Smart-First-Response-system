Smart First Response

v1

Generates the first customer reply for enterprise support tickets, and decides when a ticket should not be auto-answered at all.

 

Generate a first response

Sends the ticket straight through the LangChain chain. It always produces a reply — it has no way to decline.

POST/api/v1/generate-response

Route through the triage agent

A LangGraph state machine classifies the ticket first, then routes it: answer it, ask one clarifying question, or hand it to a human. Costs two model calls instead of one, and can refuse to reply.

POST/api/v1/generate-response/agent
